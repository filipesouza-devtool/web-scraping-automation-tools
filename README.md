# 🛠️ Web Scraping & DOM Automation Tools

Conjunto de utilitários em **JavaScript** desenvolvidos para automação de extração de dados web, seleção dinâmica de elementos no DOM e captura otimizada de recursos visuais diretamente pelo navegador.

---

### 📌 Sobre o Projeto

Este projeto reúne scripts criados para otimizar rotinas operacionais de coleta e estruturação de dados. O **scraper dinâmico** permite inspecionar, selecionar e extrair qualquer dado de uma página web diretamente pelo console, eliminando processos manuais repetitivos[](start_span)[](end_span).

---

### 🚀 Funcionalidades

- **Seleção Dinâmica DOM:** Permite capturar e estruturar elementos específicos de páginas HTML em tempo real.
- **Automação de Coleta:** Extração rápida de textos, links e dados cadastrais.
- **Execução Leve:** Roda diretamente no DevTools (Console) do navegador, sem necessidade de instalar dependências.

---

### 🛠️ Tecnologias Utilizadas

- **JavaScript (ES6+)** — Manipulação de DOM e lógica de extração.
- **HTML5 & CSS3** — Identificação de seletores e estruturas.
- **IA Generativa (Prompt Engineering)** — Auxílio na otimização dos algoritmos.

---

### 📖 Como Utilizar

1. Acesse a página web onde deseja extrair os dados.
2. Abra as Ferramentas do Desenvolvedor (`F12` > aba **Console**).
3. Copie o código do arquivo `scraper.js`, cole no console e pressione `Enter`.
